📘 Smart Study Planner

A Smart Study Planner Web Application built using HTML, CSS, and Vanilla JavaScript to help students manage subjects, tasks, schedules, and track academic progress efficiently. The application uses Browser LocalStorage to ensure data persistence without any backend.

📌 Project Information

Project Title: Smart Study Planner

Assigned Date: 5 February

Submission Deadline: 9 February

Technologies Used: HTML5, CSS3, JavaScript (Vanilla)

Storage: Browser LocalStorage

Frameworks: ❌ Not Used

🎯 Project Objective

The primary objective of this project is to design and develop a student-centric productivity tool that allows users to:

Organize academic subjects effectively

Plan study schedules and deadlines

Manage tasks and assignments

Visualize progress through analytics

Persist data using LocalStorage

This project aims to improve time management, consistency, and academic productivity.

🧠 Problem Statement

Students often struggle with:

Managing multiple subjects

Tracking assignments and deadlines

Planning daily study schedules

Monitoring progress

The Smart Study Planner addresses these challenges by providing a centralized, interactive, and persistent planning system.
