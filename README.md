# 📘 Smart Study Planner

A **Smart Study Planner Web Application** built using **HTML, CSS, and Vanilla JavaScript** to help students manage subjects, tasks, schedules, and track academic progress efficiently.  
The application uses **Browser LocalStorage** to ensure data persistence without any backend.

## 🎯 Project Objective

The primary objective of this project is to design and develop a **student-centric productivity tool** that allows users to:

- Organize academic subjects effectively  
- Plan study schedules and deadlines  
- Manage tasks and assignments  
- Visualize progress through analytics  
- Persist data using LocalStorage  

This project aims to improve **time management, consistency, and academic productivity**.

---

## 🧠 Problem Statement

Students often struggle with:

- Managing multiple subjects  
- Tracking assignments and deadlines  
- Planning daily study schedules  
- Monitoring progress  

The **Smart Study Planner** addresses these challenges by providing a **centralized, interactive, and persistent planning system**.

## 🧩 Application Features

### 🔹 Dashboard
- Displays:
  - Total subjects  
  - Pending tasks  
  - Upcoming schedules  
- Shows:
  - Today’s tasks  
  - Today’s schedules  
- Includes progress analytics using charts  

---

### 🔹 Subject Management
- Add new subjects  
- Assign priority levels (Low / Medium / High)  
- Edit existing subjects  
- Delete subjects  
- Auto-update subject dropdowns across the app  

---

### 🔹 Task Manager
- Add tasks with:
  - Task name  
  - Deadline  
  - Related subject  
- Mark tasks as completed  
- View upcoming tasks on the dashboard
